MULTIPLAYER GAME Zone (Python Project)

Project Overview

MULTIPLAYER GAME Zone is a console-based Python project that contains four fun games in a single program. The project is designed using basic Python concepts such as functions, loops, conditional statements, lists, dictionaries, random module, and exception handling. It is suitable for beginners who want to learn Python through game development.

---

Features

- Four games in one program
- Easy text-based interface
- Input validation
- Random question and number generation
- Score calculation
- Replay option
- Beginner-friendly code

---

Games Included

1. Rock Paper Scissors

- Play against the computer.
- Set the target score.
- First player to reach the target wins.

2. General Knowledge Quiz

- 10 random questions are selected from a large question bank.
- Correct Answer: +10 marks
- Wrong Answer: −5 marks
- Final score and performance message are displayed.

3. Number Guessing Game

- Computer generates a random number between 1 and 100.
- The player guesses until the correct number is found.
- Total attempts are displayed.

4. Find the Movie Name

- A word-search style game.
- Find the hidden Bollywood movie names in the letter grid.
- Correct answers are counted until all movies are found.

How to Run

1. Install Python 3.
2. Download or copy the project file.
3. Open Terminal or Command Prompt.
4. Run:

python RD_Gaming_Zone.py

5. Select a game from the menu and enjoy.
